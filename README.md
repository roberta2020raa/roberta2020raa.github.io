# Atalho para o portfólio de Roberta Alves

Este repositório mantém o endereço curto do meu portfólio **Do volante para as telas**. Ao acessar [roberta2020raa.github.io](https://roberta2020raa.github.io/), o navegador redireciona automaticamente para o portfólio publicado.

## Como funciona

O GitHub Pages publica o `index.html` deste repositório. Esse arquivo configura o redirecionamento e oferece um link manual caso ele não aconteça. Também define o título, a descrição e a imagem da prévia de compartilhamento do endereço curto.

## Onde ficam os arquivos do portfólio

O código e o conteúdo do portfólio ficam no repositório [`nova-landing-page`](https://github.com/roberta2020raa/nova-landing-page). Para editar o destino do atalho ou a prévia de compartilhamento, use o `index.html` deste repositório.

[Acessar o portfólio pelo link direto](https://roberta2020raa.github.io/nova-landing-page/)
